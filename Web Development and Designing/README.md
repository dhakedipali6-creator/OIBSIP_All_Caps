# ☕ Coffee Shop Landing Page

A modern and responsive **Coffee Shop Landing Page** developed as part of the **OIBSIP Web Development and Designing Internship – Level 1, Task 1**.

## 📌 Project Overview

This project is a visually appealing coffee shop landing page designed to provide a clean, engaging, and user-friendly experience.

The website showcases the coffee shop, its offerings, special items, collections, customer reviews, and contact information through a responsive web interface.

## ✨ Features

* ☕ Attractive hero section
* 📱 Responsive design
* 🧭 Navigation bar
* 🍵 Today's Special section
* 📖 Our Story section
* 🖼️ Signature Collections gallery
* ⭐ Customer Reviews section
* 📞 Contact information
* 🔗 Social media links

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (used for scroll-based header background change)

The objective of this task was to design and develop a responsive and visually appealing landing page while applying HTML, CSS, JavaScript, responsive design, and UI development concepts.
